# MPU6050 Module

## Purpose
The `mpu6050` module provides a driver for communicating with the MPU6050 IMU over I2C. It initializes the sensor, configures fixed operating parameters, performs gyroscope calibration, and returns fully scaled accelerometer, gyroscope, and temperature measurements. The module hides register-level operations from the rest of the firmware.

---

## Responsibilities
- Initialize the I2C interface and configure the MPU6050.
- Verify device identity using the `WHO_AM_I` register.
- Read raw sensor data and convert it into engineering units.
- Perform gyroscope zero-rate calibration.
- Provide thread-safe sensor access using an internal mutex.

---

## Public API

### `esp_err_t mpu6050_init(void)`
Initializes the module, configures the I2C driver if necessary, verifies the connected sensor, and programs the MPU6050 registers with fixed operating settings. The function must complete successfully before any sensor readings are requested.

### `esp_err_t mpu6050_read(mpu6050_data_t *data)`
Reads one complete sensor sample consisting of acceleration, angular velocity, temperature, and timestamp. Raw register values are converted into engineering units and stored in the caller-provided structure.

### `esp_err_t mpu6050_calibrate_gyro(uint16_t sample_count)`
Calculates gyroscope offsets by averaging multiple stationary samples. The computed offsets are stored internally and automatically applied during future sensor reads.

---

## Important Internal Functions

### `mpu6050_write_reg_locked()`
Writes a single byte to a sensor register while assuming the caller already owns the I2C mutex. It is used throughout initialization to configure the device.

### `mpu6050_read_regs_locked()`
Reads one or more consecutive registers while the mutex is held. This helper is shared by initialization and data acquisition routines.

### `mpu6050_read_raw()`
Performs a burst read of accelerometer, temperature, and gyroscope registers in a single I2C transaction. It acquires the mutex internally before accessing the shared I2C bus.

---

## Data Flow
The application first calls `mpu6050_init()` to configure the device. Optional gyroscope calibration is performed through `mpu6050_calibrate_gyro()`, which stores internal offset values. Each call to `mpu6050_read()` performs a burst register read, converts raw measurements into engineering units, applies gyroscope offsets, timestamps the sample, and returns the populated structure.

---

## Dependencies
The module depends on the ESP-IDF I2C driver for communication, FreeRTOS mutexes for thread synchronization, `esp_timer` for timestamp generation, and ESP logging utilities for diagnostics. Configuration values such as GPIO pins, I2C port, and timing parameters are obtained from `config.h`.

---

## Key Design Decisions
The accelerometer and gyroscope full-scale ranges are fixed during initialization instead of being configurable. Sensor readings are returned in engineering units so other modules never interact with raw register values. Thread safety is achieved with an internal I2C mutex, while gyroscope calibration is implemented as an explicit startup operation rather than occurring automatically during initialization.
